# UX/UI Design System

## Philosophy

NEXUS should feel like a trusted companion, not a machine. The interface should be warm, calm, purposeful, and never overwhelming.

## Design principles

1. Surface only what needs attention.
2. Explain AI actions clearly.
3. Use emotionally warm language.
4. Apply domain color coding consistently.
5. Keep the primary navigation simple.
6. Make sensitive AI actions reversible where possible.
7. Design child mode with safety, simplicity, and accessibility.

## Core screens

- Onboarding.
- Personal Dashboard / Life Hub.
- AI briefing.
- Health module.
- Education module.
- Fitness module.
- Family Hub.
- Child Safe Mode.
- Digital Twin screen.
- Memory timeline.
- Corporate Command Centre.
- Marketing Intelligence.
- HR + Talent.
- Finance + Growth.
- Operations.
- Notifications.
- Settings and data controls.

## Responsive behavior

- Desktop: sidebar and multi-column dashboards.
- Tablet: simpler navigation and single/two-column layouts.
- Mobile: bottom tabs, swipe cards, and full-screen module views.

## Accessibility

Target WCAG 2.1 AA, minimum 44x44 touch targets, readable contrast, screen reader summaries for AI-generated content, dynamic type support, and reduced-motion support.
