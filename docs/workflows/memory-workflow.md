# Memory Workflow

NEXUS memory is the foundation of personalization, Digital Twin, and Generational Memory.

## Flow

```text
Interaction or event
        ↓
Classify whether it should become memory
        ↓
Consent and sensitivity check
        ↓
Summarize into an episodic memory card
        ↓
Generate semantic embedding
        ↓
Store in vector DB with metadata
        ↓
Update long-term user model
        ↓
Expose in Memory screen and future retrieval
```

## Memory categories

- Health
- Learning
- Goals
- Family
- Work
- Milestones
- AI insights
- Preferences
- Relationship context

## User controls

Users must be able to search, inspect, edit, archive, export, and delete memories. Family and child memories require additional access rules.
