# Team Structure and Hiring Plan

## Founding leadership

- CEO: product vision, consumer platform instinct, B2B sales instinct, investor/media narrative.
- CTO: distributed systems, AI infrastructure, real-time pipelines, cloud scale, reliability.
- Chief AI Officer: LLM fine-tuning, multimodal AI, AI safety, model evaluation, agent systems.
- CPO: consumer UX, B2B workflow understanding, emotional product design, UX research.

## Phase 1 engineering

Lean and senior:

- AI/ML engineers for Life Orchestrator, domain agent framework, initial fine-tuned models.
- Backend engineers for data platform and API layer.
- Frontend engineer for web MVP.
- Mobile engineer for iOS/Flutter mobile MVP.
- DevOps/security engineer from day one.

## Phase 2 AI safety and ethics

- AI safety engineers.
- Red-team program.
- Bias auditing.
- AI decision explainability.
- Child safety technical controls.
- Quarterly AI safety reports.

## Culture filters

- AI works in user interest.
- Privacy is a right.
- Radical transparency.
- User sovereignty over data.
- No advertising, ever.
