# Next.js Web Application


> This folder is intentionally documentation-only for now. It defines ownership, responsibilities, data flow, and future implementation boundaries. No application code is included in this generated structure.



The web app provides the primary desktop and responsive browser experience for personal users, families, professionals, and corporate accounts.

## Key UX principles from the product document

- The AI should feel like a trusted companion, not a machine.
- The visual language should be warm, calm, and purposeful.
- Information hierarchy should surface only what needs attention.
- AI transparency should explain what the system did and why.
- Domain colour coding should help navigation by memory: health, education, fitness, AI intelligence, finance, family, and corporate modules each get consistent visual identity.

## Main experiences

- Landing and onboarding.
- Personal dashboard / Life Hub.
- AI briefing panel.
- Health, education, fitness, finance, family, digital twin, memory, and social modules.
- Corporate mode switch.
- Corporate Command Centre.
- Marketing Intelligence screen.
- HR + Talent screen.
- Finance + Growth screen.
- Operations screen.
- Notifications centre.
- Settings, data controls, consent, and audit trail.

## What belongs here

- UI routes.
- Server components and client components.
- State management.
- API SDK usage.
- Form and interaction logic.
- Accessibility implementation.

## What does not belong here

- Business rules that must be secure.
- AI model logic.
- Hidden permission checks.
- Sensitive data transformations.
