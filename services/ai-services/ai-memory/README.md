# Generational Memory and Context Service


> This folder is intentionally documentation-only for now. It defines ownership, responsibilities, data flow, and future implementation boundaries. No application code is included in this generated structure.



Owns long-term memory, episodic memory, semantic memory, embeddings, and retrieval.

## Responsibilities

- Convert important interactions into structured memory.
- Store short-term, medium-term, and long-term memory layers.
- Generate embeddings for semantic retrieval.
- Support natural-language memory search.
- Maintain memory permissions across personal, family, child, and corporate contexts.
- Power Generational Memory and Digital Twin personalization.

## Memory types

- Session context.
- Recent episodic summaries.
- Long-term semantic preferences.
- Milestones.
- Health and learning history.
- Family memories.
- Corporate knowledge memories.

## Privacy rules

Users must be able to inspect, edit, export, and delete memory. Child memories need stricter controls and family-specific access policies.
