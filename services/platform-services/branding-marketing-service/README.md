# Branding & Marketing Service

Corporate brand builder + AI campaign engine for the NEXUS / Zad Social platform
(PDF Module 6 — AI Branding + Marketing Intelligence). Companies build a brand kit and
generate multi-channel campaign briefs; AI generation is routed through `ai-model-router`.

- **Framework:** NestJS (TypeScript) · **Port:** `4121` · **Global prefix:** `/api`
- **Persistence:** PostgreSQL (TypeORM) — `brands`, `campaigns`
- **Auth:** `ZeroTrustGuard` (RS256) + per-request **company membership** check via `company-service`
- **AI:** brand/campaign generation via `ai-model-router` (deterministic fallback)
- **Transport:** Kafka consumer (`gdpr.user.deletion.requested`) in hybrid mode

## Responsibility

- **Brand kit** — a company's identity: name, tagline, colour palette, typography, voice.
- **AI Brand Identity Builder** — generate naming/tagline/palette/voice suggestions.
- **AI Campaign Engine** — generate a multi-channel campaign brief from a goal + channels.
- **Multi-tenant isolation** — every route verifies the caller is a member of the company
  (HTTP to `company-service`), **fail-closed**.
- **GDPR** — anonymises a deleted user's authorship on retained company assets.

## HTTP API

All routes require a Bearer token; the caller is `req.user.sub` and must be a company member.

| Method | Path | Description |
|---|---|---|
| `POST` | `/api/companies/:companyId/brands` | Create a brand kit |
| `GET` | `/api/companies/:companyId/brands` | List brands |
| `POST` | `/api/companies/:companyId/brands/generate` | AI brand suggestions. Body: `name?, positioning?` |
| `POST` | `/api/companies/:companyId/campaigns` | Create a campaign (AI brief). Body: `name, goal, channels?, brandId?` |
| `GET` | `/api/companies/:companyId/campaigns` | List campaigns |
| `GET` | `/api/brands/:id` | Get a brand |
| `PUT` | `/api/brands/:id` | Update a brand |
| `GET` | `/api/campaigns/:id` | Get a campaign |
| `PUT` | `/api/campaigns/:id/status` | Update status. Body: `status` (draft/active/paused/completed) |

## AI generation

Brand suggestions and campaign briefs are generated by routing a prompt through
`ai-model-router` (`POST /route`, `task_type=generation`). If the router is unavailable,
a deterministic template is returned instead, and campaigns record `aiGenerated=false`.

## Events (Kafka)

| Topic | Direction | Handler |
|---|---|---|
| `gdpr.user.deletion.requested` | consume | Anonymise the user's `createdBy` on brands/campaigns |

## Data model

- **Brand** — `id, companyId, name, tagline?, palette (jsonb), typography (jsonb), voice?, createdBy, createdAt, updatedAt`
- **Campaign** — `id, companyId, brandId?, name, goal, channels (jsonb), status, brief?, aiGenerated, createdBy, createdAt`

## Data sensitivity

**Corporate confidential** — brand assets and campaign strategy. Access is gated by
company membership; AI prompts are routed as `public` sensitivity (no personal data).
