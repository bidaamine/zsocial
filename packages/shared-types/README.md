# Shared Types


> This folder is intentionally documentation-only for now. It defines ownership, responsibilities, data flow, and future implementation boundaries. No application code is included in this generated structure.



## Responsibility

Shared enums, DTO names, user roles, account types, module identifiers, sensitivity classifications, and common platform concepts.

## Rules

Shared packages must remain generic. They should not contain application-specific secrets, database access, model calls, or heavy runtime logic.
